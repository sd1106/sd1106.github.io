The Self-Playing Ukulele

The Self-Playing Ukulele is an electromechanical instrument that reads sheet music and plays autonomously using an ESP32-S3 microcontroller running custom firmware. The hardware uses four stepper motors on timing belts to slide fretting carriages down the neck, four press servos to hold strings down on frets, and four strum servos to pluck the strings. It pairs with a host Python script that converts PDF sheet music into MusicXML and sends real-time serial commands over USB to coordinate the motors.

ESP32 Firmware Python Mechanical Build

What I Learned

Mechanical reliability was the hardest part of the whole project. Getting servos and steppers to consistently and precisely pluck/fret strings took far more iteration than the software side.

Ping-Pong ML Agent Simulation

Ping-Pong ML Agent Simulation is a physics-driven Unity environment designed to train autonomous table tennis agents using deep reinforcement learning via Unity's ML-Agents Toolkit. The project models cooperative table tennis rallies by training neural network models with Proximal Policy Optimization (PPO) to master paddle positioning, trajectory prediction, and shot interception.

Reinforcement Learning Unity ML-Agents ONNX

What I Learned

I learned how to implement and fine-tune Proximal Policy Optimization (PPO) algorithms to train autonomous agents for real-time trajectory prediction and shot interception in Unity. Additionally, I learned how to serialize trained neural network models into ONNX format for low-latency, real-time runtime inference directly within a physics-driven environment.

Lyrical Layer

Lyrical Layer is a predictive writing assistant and interactive game powered by a custom Trie data structure built in Java. It utilizes custom datasets to analyze lyric patterns from Taylor Swift and Kendrick Lamar, generating real-time character and word predictions as well as percentage-based next-word options. The application also features visual text validation and an interactive lyric-guessing game to help songwriters decompress.
